# 工业数据建模实战规范 (第二分册)
## 算术泄露排查与类别特征治理规范 (SOP)

---

## 1. 核心目标变量算术泄露排查（最高优先级）

### 1.1 为什么必须先排查？
在工厂 ERP 与 MES 系统中，大多数监控与考核指标（如工时偏差、合格率、废品率、综合能耗）**天生就是系统后台通过公式算出来的**。
若不加甄别直接把整张大表输入算法，模型会迅速找到这个“数学后门”，靠简单的四则运算取得看似 99% 的虚假预测精度，导致真正的物理工艺机理被完全掩盖，且排产前根本无法落地应用。

### 1.2 两步通用排查与隔离法
无论处理哪个工序、哪类工业数据，一律执行以下两步：

#### 步骤 1：逆向残差实锤检验
向车间业务人员明确目标指标 $Y$ 的记账定义。若怀疑 $Y$ 是由某些字段算出来的，直接写代码进行残差验证：
```python
# 示例：验证 Y 是否等于 A / (B * C) - D
derived_Y = df['A'] / (df['B'] * df['C']) - df['D']
residual = np.abs(derived_Y - df['Y'])

# 只要残差极小的比例超过 90%，直接判定为算术泄露，触发熔断
if (residual < 1e-4).mean() > 0.90:
    print("[CRITICAL] 发现算术恒等式泄露！该公式组成项必须从预测特征库彻底剔除！")
```

#### 步骤 2：因果时间轴硬性隔离
以**“业务决策时点（$t_0$）”**为唯一分界线，对字段进行一刀切：
- **事前可见**（决策时点前已知，如计划批量、设备型号、出厂图纸尺寸） $\to$ **合法特征（保留）**；
- **事后生成**（决策时点后才产生，如实际打卡工时、实际完工条数、事后质检状态） $\to$ **事后违规变量（坚决剔除出特征库，仅留作审计）**。

## 2. 非数值（类别型）字段分类治理

工业数据中的非数值字段绝不能“一刀切”，必须精准分流处理：

### 2.1 严禁踩的两大业余死穴
1. **严禁乱编 1, 2, 3（Label Encoding 陷阱）**：
   把无序的“配方A”编成 1，“配方B”编成 2，会给模型强行注入虚假的大小顺序与线性距离假设；
2. **严禁盲目独热展开（One-Hot 维度爆炸陷阱）**：
   若全厂有数百个配方代号或工号，展开为数百列稀疏矩阵，会极度稀释树模型的切分能力，导致严重过拟合。

### 2.2 三类工业分流法则

```text
非数值（文本 / 代号）字段
       │
       ├──> 1. 内嵌物理量纲（伪文本） ──> 正则提取真实物理数值（转为 float）
       │
       ├──> 2. 低基数名义类别 (≤ 10)  ──> 二元开关映射为 0.0/1.0，或轻量 One-Hot
       │
       └──> 3. 高基数工艺代号 (数十~数百) ──> 原生在线目标编码（Ordered Target Encoding）
```

#### 类别 1：内嵌真实物理量纲的“伪文本”（提取真数值）
凡是文本中包含真实尺寸、车速、乘法结构的，必须还原为连续数值：
- **剥离字母前缀**：如 `"A=12.5"` $\to$ 去掉前缀转为浮点数 `12.5`；
- **行业物理映射**：如轮胎速度级别 `"H"`、`"V"` $\to$ 映射为标准最高车速 `210.0`、`240.0 km/h`；
- **解析乘法结构**：如钢丝代号 `"6x6"` $\to$ 正则解析乘法，还原为钢丝总根数 `36.0`；
- **复合规格解耦**：如复合尺寸 `"235/50 R 19"` $\to$ 正则一分为二，拆解出断面宽（`235.0 mm`）与扁平比（`50.0%`）。

#### 类别 2：低基数名义类别（唯一值 $\le 10$）
- **二元物理开关**：如原厂配套标识（`Y/N`），直接严格映射为 `1.0 / 0.0`；
- **少量系列代号**：如 3~5 种机台大类，可保留原生文本或采用 One-Hot 独热编码。

#### 类别 3：高基数工艺代号（数十至数百种配方号、物料代号）
- **最优实践**：保留干净原生字符串，交由 **CatBoost 原生在线目标编码（Ordered Target Encoding）** 处理，算法会在折内按顺序基于历史样本平滑统计，从数学上杜绝预测漂移；
- **替代方案（LightGBM / XGBoost）**：必须在交叉验证的**训练折内部**做带平滑的目标编码，测试折只读映射，**严禁全表偷看目标标签**！

## 3. 落地自检清单 (Checklist)

| 序号 | 检查维度 | 判定标准 | 状态 |
| :---: | :--- | :--- | :---: |
| 1 | **算术泄露排除** | 是否已验证目标标签 $Y$ 与各输入特征不存在代数算术恒等关系？ | `[PASS]` |
| 2 | **时间轴隔离** | 预测特征库里是否已彻底剔除决策时点 $t_0$ 之后才产生的事后字段？ | `[PASS]` |
| 3 | **内嵌真值提取** | 文本中隐藏的车速、乘法根数、复合规格是否已正则提取为物理连续数值？ | `[PASS]` |
| 4 | **拒绝伪数字编码** | 高基数无序配方代号是否杜绝了乱编 1,2,3，且未盲目展开成数百维稀疏矩阵？ | `[PASS]` |
