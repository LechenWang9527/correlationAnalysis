# 工业数据预处理实战规范

---

## 1. 目标变量算术泄露排查（最高优先级）

在工厂系统里，工时偏差、合格率、单耗等考核指标，往往是系统后台用公式直接算出来的。若不加甄别直接把整张表喂给模型，算法会直接做四则运算（虚假 99% 精度，排产时根本无法使用）。必须在清洗前置排查：

1. **逆向残差实锤检验**：向车间确认目标指标 $Y$ 的记账逻辑，用代码验证是否有字段能直接算出 $Y$：
   ```python
   # 示例：验证 Y 是否等于 A / (B * C) - D
   derived_Y = df['A'] / (df['B'] * df['C']) - df['D']
   residual = np.abs(derived_Y - df['Y'])
   if (residual < 1e-4).mean() > 0.90:
       print("[CRITICAL] 发现算术恒等式泄露！该公式组成项必须从预测特征库彻底剔除！")
   ```
2. **因果时间轴硬性隔离（通用 $t_0$ 准则）**：以业务决策时刻 $t_0$ 为界：
   - **事前已知**（$t_0$ 前可查，如计划量、设备型号、图纸尺寸） $\to$ **合法特征（保留）**；
   - **事后生成**（$t_0$ 后才发生，如打卡工时、完工数量、质检结果） $\to$ **事后泄露项（坚决剔除出特征库，只留作审计）**。

---

## 2. 基础数据清洗与物理去噪

1. **剔除无意义列与伪常数列**：
   - 移除系统导出遗留的行号索引（如 `Unnamed: 0`）与全空格死列（如占比超 90% 的空白字段）；
   - 移除全表唯一值的绝对常数列；
   - 过滤单一取值占比 $\ge 98\%$ 的伪常数列，但对关键出厂工艺参数设立白名单强制保护，严防误删；
   - 剔除严格代数派生列（如周长等于 $\pi \times$ 内径、长宽固定加常数）与文本镜像列。
2. **区分“物理结构性缺失”与“数据采集丢失”**：
   - **物理结构性缺失（本来就没有）**：如单层胎体天生没有第二层帘布，普通轻型胎天生没有加强包布。**严禁全局填均值**！数值型强制赋 `0.0`，文本型赋 `Not_Present`，并同步新增 `Has_*` 布尔指示列（0/1）明确结构差异；
   - **采集丢失（传感器故障或丢包）**：保留缺失状态或在交叉验证折内进行局部插补。
3. **系统微观异常负数修正**：
   - 对工时、覆盖率等物理非负字段出现的极微小负数（系统跨零点同步漂移），使用 `.clip(lower=0)` 安全截断归零；
   - 建立行级映射记录源行哈希（标记 `NEGATIVE_CLIPPED`），确保同工单内有正常记录，不破坏完工事实。
4. **全局去重与无死角断言**：
   - 全局删除跨班次导出的一模一样冗余行；
   - 清洗脚本末尾必须执行严格断言，确保全表 `0 NaN`、数值列 `0 Inf`，并将各列类型、上下界固化为机器契约（`feature_schema.json`）。

---

## 3. 非数值（类别型）字段分类治理

严禁将无序代号盲目编为 1, 2, 3（引入虚假大小关系），严禁对高基数代号直接 One-Hot（导致维度爆炸与过拟合）。工业数据非数值列分为三类处理：

1. **内嵌物理量纲的“伪文本”（提取真数值）**：
   - 文本中包含尺寸、车速、乘法结构的，必须正则还原为连续浮点数：
     - 去除无意义字母前缀（如 `"A=12.5"` $\to$ `12.5`）；
     - 行业代号映射为物理量（如轮胎速度代号 `"H"` $\to$ 最高车速 `210.0 km/h`）；
     - 正则解析乘法算式（如钢丝代号 `"6x6"` $\to$ 还原为总根数 `36.0`）；
     - 复合规格拆解（如 `"235/50 R 19"` $\to$ 正则拆出断面宽 `235.0 mm` 与扁平比 `50.0%`，原规格字符串留作宏观分组）。
2. **低基数名义类别（唯一值 $\le 10$）**：
   - 二元物理开关（如原厂配套标识 Y/N、双配方切换）严格映射为 `1.0 / 0.0`；
   - 少量机台大类可保留干净文本或轻量独热编码。
3. **高基数工艺代号（数十至数百种配方号、物料代号）**：
   - 保留干净文本字符串，交由支持类别特征的算法（如 CatBoost）采用**在线排序目标编码（Ordered Target Encoding）**处理；
   - 若使用其他树模型，必须在交叉验证训练折内部做平滑目标编码，**严禁全表偷看目标标签**。

## 4. 特征统计初筛与分层反转排查（试纸 A 与试纸 B）

在复杂模型进场前，必须通过双试纸完成特征健康体检，摸清特征单兵能力并排查设备混杂反转。

### 4.1 试纸 A：单特征体检与打假
对每个特征执行多口径扫描，防范单一度量误杀非线性黑马：
1. **数值列“四镜齐照”**：同步计算 Pearson 线性系数、Spearman 秩相关、决策树分箱 $R^2_{\text{binned}}$、以及广义距离相关系数（dCor，专抓 U 型与高阶非线性）；类别列计算 ANOVA 效应量 $\eta^2$ 与无偏 $\omega^2$；
2. **防伪双重质控**：矩阵中混入一列标准高斯随机伪特征（`Noise_Sentinel ~ N(0, 1)`），并用 Benjamini-Hochberg (BH) 算法实施多重检验校正，将假发现率控制在 $q < 0.05$；
3. **单特征四级准入与救回门槛**：
   - **🟢 绿灯（强信号主力）**：校正 $q < 0.05$ 且（有效解释率 $\ge 10\%$ 或 $\text{dCor} \ge 0.25$）；
   - **🟡 黄灯（有效特征 / 隐藏黑马）**：校正 $q < 0.05$ 且（$2\% \le \text{有效解释率} < 10\%$ 或 $\text{dCor} \ge 0.12$）。若线性 $R^2 < 1\%$ 但分箱树或 dCor 达标，打上 `[线性误杀预警]` 强力保留；
   - **⚪ 灰灯（辅助信号）**：$q < 0.05$ 且解释率在 $0.3\% \sim 2\%$ 之间；
   - **🔴 红灯（淘汰弃用）**：$q \ge 0.05$，或解释率 $< 0.3\%$ 且未能显著超越高斯随机哨兵。
4. **全数据集准入底线**：Top 1 特征有效解释率必须 $\ge 10\%$ 且 $q < 0.05$。若全表无一特征解释率达到 2%，判定为纯噪声数据，直接熔断叫停！

### 4.2 试纸 B：多特征协同团战与辛普森悖论排查
抽样 5000 条代表性样本跑 5 折交叉验证，检验多特征协同能力并扫描车间分层反转：

1. **多特征协同通关门槛（双保险）**：
   - **【硬指标 1：绝对水平底线】** 5 折 CV 的测试集 $R^2$ 必须 $\ge 15\%$（冲破 $30\%$ 为绿灯强可用，低于 $15\%$ 熔断淘汰，严禁在个位数垃圾信号上过拟合）；
   - **【硬指标 2：相对防伪检验】** 真实特征的测试集 $R^2$ 必须 100% 击败 19 次目标标签打乱洗牌（Permutation 经验显著性 $p \le 0.05$），彻底排除特征凑数的偶然巧合。
2. **辛普森悖论分层排查（防机台设备混杂打脸）**：
   按车间机台（WorkCenter）或产品规格（tire_size）将数据切片（组内样本量 $\ge 200$），扫描两类警报触发器：
   - **正负双向撕裂**：最大子组相关 $r_{\text{max}} > +0.20$ 且 最小子组相关 $r_{\text{min}} < -0.20$（组间方向完全相反）；
   - **全局盲区掩盖**：全厂汇总相关 $|r_{\text{global}}| < 0.05$，但局部子组最大相关 $\ge 0.30$（被组间均值差强行抵消）；
   - **应对底线**：若大面积触发反转警报，证明存在强烈的设备/规格混杂，**后续建模严禁全表完全随机切分**！必须通过工单聚合、以工单族或机台为单元实施分组隔离（GroupKFold）。

## 5. 基座模型竞技与算法选型规范

在工业离散制造表格数据中，深度神经网络参数臃肿、易过拟合且缺乏可解释性，模型选型严格遵循**“多模型竞技对账，CatBoost 单模工业交付”**原则：

1. **搭建多模型竞技场**：
   - **Ridge 线性回归（及格线标尺）**：作为线性基线，用来度量树模型在非线性交互上的净增益；
   - **LightGBM / XGBoost（经典对照先锋）**：基于直方图与二阶梯度展开，验证梯度提升树在离散样本上的基础拟合能力。
2. **最终锁定 CatBoost 作为主力基座（三大工业优势）**：
   - **原生支持高基数配方代号**：车间有上百种离散橡胶配方，CatBoost 底层自带**在线排序目标编码（Ordered Target Encoding）**，在折内按顺序平滑统计，从数学上杜绝标签泄露与预测漂移；
   - **对称决策树（Oblivious Trees）抗噪极强**：每层切分条件全局一致，固定深度（depth=6，64个叶子），结构简洁抗过拟合，毫秒级推理；
   - **与 TreeSHAP 原生无缝契合**：底层 C++ 极速遍历树路径，能够毫秒级计算全量工单的 Shapley 边际贡献，为后续工艺参数归因与因果分析提供坚实依据。
3. **工程交付底线**：
   - 实验阶段允许多模型横评对比；
   - **产线工程落地时一律采用 CatBoost 单模交付**，杜绝加权集成导致的多模型版本同步、内存暴涨与多套特征工程对齐等运维灾难。
