# 工业数据预处理与归因操作规范

---

## 1. 目标变量算术泄露排查（最高优先级）

在工厂系统里，工时偏差、合格率、单耗等考核指标，往往是系统后台用公式直接算出来的。若不加甄别直接把整张表用作模型输入，算法会直接做四则运算（可能显示出 99% 的表面精度，但排产时缺少这些字段）。必须在清洗前置排查：

1. **目标恒等式残差核验**：向车间确认目标指标 $Y$ 的记账逻辑，用代码验证是否有字段能直接算出 $Y$：
   ```python
   # 示例：验证 Y 是否等于 A / (B * C) - D
   derived_Y = df['A'] / (df['B'] * df['C']) - df['D']
   residual = np.abs(derived_Y - df['Y'])
   if (residual < 1e-4).mean() > 0.90:
       print("[FAIL] 发现算术恒等式泄露。请从预测特征中排除公式组成项。")
   ```
2. **因果时间轴硬性隔离（通用 $t_0$ 准则）**：以业务决策时刻 $t_0$ 为界：
   - **事前已知**（$t_0$ 前可查，如计划量、设备型号、图纸尺寸） $\to$ **合法特征（保留）**；
   - **事后生成**（$t_0$ 后才发生，如打卡工时、完工数量、质检结果） $\to$ **事后泄露项（坚决剔除出特征库，只留作审计）**。

---

## 2. 基础数据清洗与物理去噪

1. **剔除无意义列、衍生列与强相关冗余列**：
   - 移除系统导出遗留的行号索引（如 `Unnamed: 0`）与以空格为主的列（如占比超 90% 的空白字段）；
   - 移除全表唯一值的绝对常数列，以及单一取值占比 $\ge 98\%$ 的近常数列（但对关键出厂工艺参数设立白名单强制保护，严防误删）；
   - **严格数学衍生列直接剔除**：凡可通过其他列经过加减乘除确定算出的衍生列（如 `quantity gap == QuantityDone - PlannedQuantity`、周长等于 $\pi \times$ 内径、一层带宽恒等于二层带宽 $+ 10\mathrm{mm}$），以及 一一对应的等价文本列，一律直接剔除，减少重复信息；
   - **强相关冗余列分流处理**：对全表线性/秩相关极高（如 $|r| \ge 0.95$）且物理含义高度重合的相似特征，清洗阶段仅保留物理语义最直接的主代表列；对存在合理工艺微差但强相关的同部件尺寸（如胎面重量与胎面底胶宽），保留至建模阶段，并在后续归因中采用**模块化消融（LOCO）与合流 SHAP** 统一评价，防止单特征重要性因相关性而分散。
2. **区分“物理结构性缺失”与“数据采集丢失”**：
   - **物理结构性缺失（本来就没有）**：如单层胎体天生没有第二层帘布，普通轻型胎天生没有加强包布。**严禁全局填均值**！数值型强制赋 `0.0`，文本型赋 `Not_Present`，并同步新增 `Has_*` 布尔指示列（0/1）明确结构差异；
   - **采集丢失（传感器故障或丢包）**：保留缺失状态或在交叉验证折内进行局部插补。
3. **系统微观异常负数修正**：
   - 对工时、覆盖率等物理非负字段出现的极微小负数（系统跨零点同步漂移），使用 `.clip(lower=0)` 安全截断归零；
   - 建立行级映射记录源行哈希（标记 `NEGATIVE_CLIPPED`），确保同工单内有正常记录，不破坏完工事实。
4. **全局去重与结果检查**：
   - 全局删除跨班次导出的完全重复行；
   - 清洗脚本末尾必须执行严格断言，确保全表 `0 NaN`、数值列 `0 Inf`，并将各列类型、上下界固化为机器契约（`feature_schema.json`）。

## 3. 非数值（类别型）字段分类治理

严禁将无序代号直接编为 1, 2, 3（引入虚假大小关系），严禁对高基数代号直接 One-Hot（导致列数大幅增加与过拟合）。工业数据非数值列分为三类处理：

1. **内嵌物理量纲的“伪文本”（提取真数值）**：
   - 文本中包含尺寸、车速、乘法结构的，必须正则还原为连续浮点数：
     - 去除无意义字母前缀（如 `"A=12.5"` $\to$ `12.5`）；
     - 行业代号映射为物理量（如轮胎速度代号 `"H"` $\to$ 最高车速 `210.0 km/h`）；
     - 正则解析乘法算式（如钢丝代号 `"6x6"` $\to$ 还原为总根数 `36.0`）；
     - 复合规格拆解（如 `"235/50 R 19"` $\to$ 正则拆出断面宽 `235.0 mm` 与扁平比 `50.0%`，原规格字符串留作宏观分组）。
2. **低基数名义类别（唯一值 $\le 10$）**：
   - 二元物理开关（如原厂配套标识 Y/N、双配方切换）严格映射为 `1.0 / 0.0`；
   - 少量机台大类可保留干净文本或轻量独热编码。
3. **高基数工艺代号（数十至数百种配方号、物料代号）**：
   - 保留干净文本字符串，交由支持类别特征的算法（如 CatBoost）采用**在线排序目标编码（Ordered Target Encoding）**处理；
   - 若使用其他树模型，必须在交叉验证训练折内部做平滑目标编码，**编码器仅使用训练折的标签**。

## 4. 特征统计初筛与分层反转排查（Step 2A 与 Step 2B）

先筛查单个特征与目标的关系，再比较多变量模型，并检查按设备和规格分组后的相关性。

### 4.1 Step 2A：单特征筛查
对每个特征执行多口径扫描，避免只看线性指标而漏掉非线性关联：
1. **数值列多维评估**：同步计算 Pearson 线性相关系数、Spearman 秩相关、十五等频分箱 $R^2_{\text{binned}}$、以及广义距离相关系数（dCor，用于捕获 U 型与高阶非线性关系）；类别列计算 ANOVA 效应量 $\eta^2$ 与无偏 $\omega^2$；
2. **噪声对照与多重检验校正**：在特征矩阵中加入一列标准正态随机噪声（`__shadow_random_noise__`）作为对照底线，并用 Benjamini-Hochberg (BH) 算法实施多重检验校正，将假发现率严格控制在 $q < 0.05$；
3. **单特征四档评级**。脚本按下列顺序判定。
   - 若校正后 $q \ge 0.05$，评级为 `INSIGNIFICANT`。
   - 对于 $q < 0.05$ 的特征，有效解释率 $\ge 10\%$ 或 $\text{dCor} \ge 0.25$ 时为 `HIGH`。
   - 其余特征中，有效解释率 $\ge 2\%$ 或 $\text{dCor} \ge 0.12$ 时为 `MEDIUM`。
   - 其余特征中，有效解释率 $\ge 0.3\%$，或 $\text{dCor}$ 严格大于 $0.08$ 与噪声对照 $\text{dCor}$ 的 $2.5$ 倍两者中的较大值时，为 `LOW`。其余为 `INSIGNIFICANT`。
   - 数值特征为 `HIGH` 或 `MEDIUM` 且线性 $R^2 < 1\%$ 时，标记 `[LOW_LINEAR_SIGNAL]`，随机噪声对照除外。备注中的 `[PASS]` 表示无额外提示，筛查评级另列。
4. **整体筛查状态**。按首位真实特征的有效解释率和校正后 $q$ 值判定。$q < 0.05$ 且有效解释率 $\ge 10\%$ 为 `[PASS]`，$q < 0.05$ 且有效解释率在 $2\%$ 至 $10\%$ 之间（含 $2\%$）为 `[WARN]`，其余为 `[FAIL]`。

### 4.2 Step 2B：多变量模型对比与辛普森悖论排查
抽样 5000 条代表性样本跑 5 折交叉验证，检验多特征协同能力并扫描车间分层反转：

1. **多变量模型验收条件**：
   - **`[GATE 1]` 绝对水平底线**：5 折 CV 的测试集 $R^2$ 必须 $\ge 15\%$（达到 $30\%$ 以上为 `[PASS_STRONG]` 强可用，低于 $15\%$ 为 `[FAIL]` 未达验收阈值）；
   - **`[GATE 2]` 目标置换检验**：真实特征的测试集 $R^2$ 须高于全部 19 次目标标签置换的得分（Permutation 经验显著性 $p \le 0.05$），用于比较原始标签与随机标签下的模型得分。
2. **辛普森悖论分层排查（成因与检查方法）**：
   - **为什么会出现辛普森悖论**：全厂汇总算出来的相关系数，常常把“不同机台的能力差”或“不同轮胎规格的基准差”混在了一起。例如车间习惯把大规格轮胎优先排在自动化程度最高的新机台生产，小规格轮胎放在老机台；好机台的速度优势抵消甚至倒挂了大轮胎本身的物理耗时，导致宏观汇总时“尺寸越大、生产反而越快”，完全掩盖或颠倒了同一机台内部真实的物理规律；
   - **分组切片扫描方法**：按核心混杂维度（生产机台 `WorkCenterNameCoupled`、产品规格 `tire_size`）将全表切分为独立子群，仅保留组内样本量 $\ge 200$ 的有效子群（剔除小样本随机抖动），分别计算组内相关系数 $r_{\text{group}}$ 与全表汇总相关系数 $r_{\text{global}}$；
   - **两类硬性警报触发器**：
     1. **组内相关方向反转**：在有效子群中，最大正相关 $r_{\text{max}} > +0.20$ 且最小负相关 $r_{\text{min}} < -0.20$，说明同一个特征在不同机台或规格下呈现截然相反的作用方向；
     2. **总体弱相关与分层强相关**：全厂汇总相关极其微弱（$|r_{\text{global}}| < 0.05$），但局部子群内的最大相关绝对值 $\ge 0.30$，说明真实的组内强关联在全表汇总时被各组均值差抵消；
   - **工程应对底线（严禁随机切分）**：一旦大面积触发上述警报（例如本项目中 49 个数值特征有 44 个触发警报），证明数据存在强烈的设备与规格混杂偏倚。后续建模**严禁对原始数据做全表随机切分**（否则同工单、同机台混杂样本会横跨训练集与测试集，评估得分可能偏高）；必须先按计划主键聚合为独立工单，再以**工单族（或机台批次）为不可分割的原子单位执行分组隔离交叉验证（GroupKFold）**。

## 5. 基准模型比较与算法选型规范

在工业离散制造表格数据中，深度神经网络参数臃肿、易过拟合且缺乏可解释性，模型选型严格遵循**“比较多种模型，工程交付采用 CatBoost 单模型”**原则：

1. **比较基准模型**：
   - **Ridge 线性回归（线性基线）**：作为线性基线，用来度量树模型在非线性交互上的净增益；
   - **LightGBM / XGBoost（树模型对照）**：基于直方图与二阶梯度展开，验证梯度提升树在离散样本上的基础拟合能力。
2. **选择 CatBoost 的依据**：
   - **原生支持高基数配方代号**：车间有上百种离散橡胶配方，CatBoost 底层自带**在线排序目标编码（Ordered Target Encoding）**，在折内按顺序平滑统计，从数学上杜绝标签泄露与预测漂移；
   - **对称决策树（Oblivious Trees）结构约束**：每层切分条件全局一致，固定深度（depth=6，64个叶子），结构简洁抗过拟合，毫秒级推理；
   - **兼容 TreeSHAP**：底层 C++ 遍历树路径，能够毫秒级计算全量工单的 Shapley 边际贡献，为后续工艺参数归因与因果分析提供坚实依据。
3. **工程交付底线**：
   - 实验阶段允许多模型横评对比；
   - **产线工程落地时一律采用 CatBoost 单模交付**，杜绝加权集成导致的多模型版本同步、内存暴涨与多套特征工程对齐等运维成本。

## 6. 多维归因协同与方法冲突裁决规范

单一归因方法极易被共线性或虚假外推误导。工业归因必须将四种互补方法串成闭环流水线，并按定量裁决标准解释方法之间的差异。

### 6.1 四步归因协同流水线
1. **第 1 步：TreeSHAP 全局特征筛查**
   - 在 5 折外验证集（OOF）上计算每个特征的 Shapley 贡献，列出全局 Top 20 候选瓶颈特征与模块合流 SHAP（同模块先有符号加总再取绝对值均值）。
   - **指标物理含义**：
     - **单点有符号 SHAP 值**（单位与目标 $Y$ 一致，如秒/胎）：在单个样本上，该特征把模型预测值相对于全厂基准均值（Base Value）推高（`+`）或拉低（`-`）的净幅度，且所有特征贡献之和严格等于最终预测偏差；
     - **全局平均绝对 SHAP 值（`Mean(|SHAP|)`）**：用于全局排名，度量该特征在所有工单上平均每次使结果偏离基准线的绝对影响力度（值越大说明预测变化越大）。
2. **第 2 步：LOCO 留一模块重训消融**
   - 将特征按工艺结构归为若干模块，每次**删除一个完整模块并重新训练模型**，计算泛化误差增量 $\Delta\mathrm{MAE}$，检验该模块是否具备“其他特征难以替代的预测信息”。
3. **第 3 步：真实供体条件置换（防虚假外推）**
   - 严禁全局随机打乱，以免组合出实际生产中不存在的规格。严格限制在**同机台、同基础规格、且其余部件 Gower 物理距离 $\le 0.14$** 的真实工单池中匹配供体（Donors），整套模块移植后测定合法工艺波动下的误差增量 $\Delta\mathrm{MAE}$。
4. **第 4 步：1D-ALE 累积局部效应（定位局部变化）**
   - 对核心连续物理特征，在满足真实样本支撑（分箱内有效工单 $\ge 50$、覆盖配方簇 $\ge 5$）的区间内计算局部差分导数积分，识别“从多少毫米/千克开始工时陡增”的区间。

### 6.2 归因结果不一致时的四种处理方式

当四个方法的结论不一致时，严禁盲目取平均，必须按以下物理机理进行分型裁决：

| 不一致现象 | 可能原因 | 标准裁决与落地解决动作 |
| :--- | :--- | :--- |
| **SHAP 高 + 条件置换高，但 LOCO 重训 $\approx 0$**<br>*(如：内衬层、胎侧模块)* | **跨模块相关性与局部变化**：移除该模块后，其他几何尺寸可能补充信息。也可能只有极端尺寸下出现变化，全局平均后不明显。 | **检查 1D-ALE 支撑区间**：在有数据支撑的区间内查找明显变化（如内衬层厚度 `>1.65mm` 陡增），车间只针对超标规格定点调优或追加宽放。 |
| **SHAP 高 + LOCO 显著，但条件置换极弱（覆盖率 `<5%`）**<br>*(如：几何胎圈、胎体模块)* | **工艺尺寸受约束**：在同机台、同轮辋及相似零件中，基础骨架尺寸受图纸约束，找不到可替换的差异供体。 | **结合 LOCO 与 SHAP 判断**：当条件置换供体覆盖率 `<5%` 时，条件置换缺少足够样本，直接将其定性为决定基准难度的“影响跨规格预测的基础特征”。 |
| **单特征 SHAP 排进前 20，但 LOCO 与条件置换双双不显著（跨 0 或为负）**<br>*(如：带束层与冠带模块)* | **归因方法衡量的内容不同**：模型用过该特征进行分裂，但替换它或删除后重训，评估误差未见明显变化。 | **同时检查两项误差指标**：只要 LOCO 与条件置换同时不显著，该特征暂不单独列入整改清单。 |
| **单特征 SHAP 排名分散，但模块 LOCO / 置换显著恶化**<br>*(如：多零件复合模块)* | **贡献分散到多个关联特征**：模块内有 6~8 个关联特征，单个特征的 SHAP 不突出，组合后可提供预测信息。 | **结合模块 LOCO 与合流 SHAP**：以模块为分析单位，按“工艺总成模块/工位”整体立项改造。 |

### 6.3 统计归因与因果干预的边界
- **物理图纸特征（严禁随意宣称反事实因果）**：出厂 BOM 尺寸与胶料配方在生产中相互绑定，车间无法在保持其他一切不变的前提下“单把某层钢丝拉宽 5mm”（缺乏反事实可操作性与共同支撑），因此物理特征只做**受控局部响应归因（SHAP + LOCO + ALE）**，不做盲目的双重机器学习（DML）反事实外推；
- **排产调度参数（可做因果干预评估）**：只有像**计划生产批量（`PlannedQuantity`）**这类调度员在现实中真能动手合单/拆单的独立决策变量，才允许进入因果干预评估，用于指导车间排产平准化与批量优化。

## 7. 系统工程落地与车间实践转化规范

模型与归因结果不能只停留在报表上，必须按以下四条路径直接转化为车间生产力：

1. **工艺与设备靶向改造（消费 `TreeSHAP + LOCO + 条件置换` 结果）**：
   - 拒绝全产线盲目大改，只对**三种方法均支持的主要物理模块**立项；
   - 结合 1D-ALE 恶化区间实施定点改造（例如：只针对宽 $>45\mathrm{mm}$ 的高硬度三角胶加装贴合微温预热装置；只针对自重 $>10\mathrm{kg}$ 的重型胎面调优供料机械手加减速参数）。
2. **IE 标准定额动态宽放（消费 `1D-ALE 阶跃拐点` 结果）**：
   - 按规格差异细分定额；
   - 直接读取 1D-ALE 曲线在明显变化点后的净抬升秒数（$\Delta Y$），为超限规格设立分段宽放系数（例如：图纸内衬层厚度超过 $1.65\mathrm{mm}$ 时，单胎标准定额自动追加 $+2.0\sim 2.5$ 秒工艺宽放），消除不合理的超时告警。
3. **APS 事前排产风险控制与合单优化（消费 `CatBoost 事前单模 + 因果变量`）**：
   - **事前超时预警**：将训练好的 CatBoost 纯事前模型（Feature Set A）封装为轻量 API 接入排产系统（APS）。排产下发前仅凭图纸和计划量秒级预判超时风险，将高耗时工单错峰分流至不同班次或高效机台，防止集中阻塞后道工序；
   - **批量合单调度**：依据可干预变量（如计划批量 `PlannedQuantity`）的规模效应，指导调度员对碎片小单合理合单，降低换模损耗。
4. **MES 数据源头治理与模型表现监测（消费 `预处理发现的问题 + 时序盲测`）**：
   - **完善 MES 数据记录**：推动信息部在 MES 底层表增设“工单唯一执行实例 ID”与录入强校验，从源头根治“多人打卡拆成多行”、“跨零点负工时”与“录入多余空格”；
   - **月度盲测监控**：每月用最新完工工单执行一次只读盲测回放（重点监控新配方冷启动误差），一旦泛化误差（MAE）突破阈值，触发季度滚动重训。
